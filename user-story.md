# User Story Template

## Title: User Registration and Authentication

### As a:
Registered User / Visitor

### I want to:
Register, log in, search for gifts, and view item details effortlessly.

### So that:
I can participate in the gift-sharing platform securely.

### Acceptance Criteria:
- [x] User can create an account via `/api/auth/register`
- [x] User can log in via `/api/auth/login`
- [x] User can view all gifts via `/api/gifts`
- [x] User can search gifts by category via `/api/search`
